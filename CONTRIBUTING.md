# Contributing

Contributions are welcome when they preserve the local-first, self-contained design.

1. Edit `src/index.template.html` and related configuration/docs.
2. Keep dependency versions pinned in `dependencies.json`.
3. Run `./scripts/check-repository.ps1` on Windows.
4. Test at least one relevant Excel, PowerPoint, or Word document.
5. Do not include confidential Office files in commits, issues, or pull requests.
