# Office Image Extractor v1.1.1

## 日本語

- Officeファイルの追加後は、ファイル選択・ドロップエリアがコンパクトになります。
- 画像の選択数とZIP保存をまとめ、絞り込み・並べ替え・同一画像の確認は折りたたみから利用できるようにしました。
- SVGのサムネイルと拡大プレビューに対応しました（16 MiB以内）。スクリプトや外部参照などを含むSVGはプレビューしませんが、元データはそのまま保存できます。
- スマートフォンでは「完全ローカル処理」バッジを非表示にしました。ファイル処理やプライバシーの仕様は変更していません。

## English

- After importing Office files, the drop target becomes a compact add-files control.
- Selected-image counts and ZIP download are grouped together; advanced filters, sorting and identical-image options are collapsible.
- SVG thumbnails and enlarged previews are available for supported files up to 16 MiB. SVGs containing scripts, external references or other unsafe content remain downloadable in their original form without a preview.
- Hide the Fully local processing badge on narrow mobile screens without changing how files are processed.

### Downloads

- `htmlapps-office-image-extractor-v1.1.1.html` — self-contained HTML, open directly in a browser.
- `htmlapps-office-image-extractor-v1.1.1.self-extract.html` — smaller, self-extracting standalone HTML.
- `htmlapps-office-image-extractor-v1.1.1.zip` — both HTML files, build manifests, English/Japanese documentation and license notices.
- `SHA256SUMS.txt` — SHA-256 checksums of the three download packages.

The release workflow publishes these files only after the official Windows repository check and Chromium `file://` browser QA succeed on the merged `main` commit.
